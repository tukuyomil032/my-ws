# 興味提案 W4 (6/22〜6/28)

## 技術系
- コードベース知識グラフ - 検出: SA1 | 理由: 個人知識基盤とエージェントの長期記憶を、ソースコード探索にも応用できる。
- AIエージェント固有IDのライフサイクル管理 - 検出: SA4 | 理由: 人間の認証管理とは別に、短命なエージェントIDの発行、委任範囲、最小権限、即時失効を設計する新しい論点として掘り下げられる。
- AI出力の形式検証 - 検出: SA4 | 理由: 自動収集・実装エージェントの結果を数学的・機械的に検証する新しい品質保証手法として関連性が高い。
- 差動原子干渉計 - 検出: SA6 | 理由: 重力波・暗黒物質探索を支える次世代計測技術で、現在の技術関心から離れた科学領域を広げられる。
- 医療AIエージェントの評価設計 - 検出: SA6 | 理由: 自律エージェントの性能だけでなく、安全性、一般化、前向き試験という評価軸を学べる。
- エージェント前提のバージョン管理 - 検出: SA1 | 理由: 並行するAIエージェントの変更・競合・履歴をGitとは異なる設計で扱うOakは、現在のサブエージェント運用に直結する。
- GitHub Actions実行保護 - 検出: SA2 | 理由: workflow起動者とイベントをrulesetで制御する仕組みは、CIのローカル検証に加えて実行権限の境界設計を深掘りできる。
- 多言語ソース診断の文字位置変換 - 検出: SA2 | 理由: UTF-8バイト位置とUTF-16コード単位の差は、日本語を含むCLI・エディタ統合で再利用性の高い実装論点になる。
- エージェント運用ハーネス比較 - 検出: SA1 | 理由: Claude Code / Codex 向けの harness や ECC が複数出ており、サブエージェント運用を再現可能にする設計比較に向く。
- TypeScript Go移行準備 - 検出: SA2 | 理由: TypeScript 6.0 が 7.0 の Go 実装移行を意識した橋渡し版になっており、フロントエンド/CLI基盤の将来変更として追う価値がある。
- Swiftパッケージ配布基盤 - 検出: SA1 | 理由: Swift Package Index の Apple 参加は、macOS/Swift 開発で使う依存発見・配布インフラの変化として継続観測に向く。
- ローカル高速検索の低レイヤー実装 - 検出: SA1 | 理由: SSD 直接読み取り型の検索実験は、個人ナレッジベースやコード探索の速度限界を考える補助線になる。

## 非技術系
- 主権AIと国家インフラ - 検出: SA1・SA4 | 理由: オープンモデル、インド独自AI基盤、国家安全保障が交差する政策テーマとして継続観測に向く。
- 現代美術市場と国際展 - 検出: SA5 | 理由: Art Baselとヴェネチア・ビエンナーレを通じ、技術以外の文化・市場動向を定点観測できる。
- 永久凍土融解と岩石風化 - 検出: SA6 | 理由: 気候変動のフィードバックが単純な一方向ではないことを示す研究テーマで、科学ニュースの解像度を上げられる。
- AI音楽訓練データと創作者同意 - 検出: SA5 | 理由: AIツールへの技術的関心を、著作権・同意・対価という文化政策の側から検討できる。
- AIデータセンターの電源調達 - 検出: SA4 | 理由: 2.67GW規模のガス火力計画は、AI計算需要と脱炭素目標の衝突を追う具体的な観測点になる。
- 恒星間彗星の同位体化学 - 検出: SA6 | 理由: 3I/ATLASのD/H比から形成環境を推定する研究は、単一天体の観測と銀河進化モデルの接続を学べる。
- 欧州熱波と社会インフラ - 検出: SA3 | 理由: 記録的熱波が鉄道・学校・観光へ波及しており、気候変動を生活インフラの運用問題として追える。
- 防衛テック投資 - 検出: SA4 | 理由: 地政学リスクとAI/ドローン投資が結びついており、通常のスタートアップ投資とは異なる政策・安全保障軸を学べる。
- 文化フェスのキュレーション設計 - 検出: SA5 | 理由: Olivia Rodrigo の女性主導フェスは、音楽作品だけでなく「場を設計する」文化的な動きとして観測できる。
- 軌道上サービスと宇宙望遠鏡延命 - 検出: SA6 | 理由: Swift宇宙望遠鏡の救出計画は、商業宇宙企業が科学観測インフラの寿命を延ばす新しい役割を示している。
