# 興味提案 W4 (6/22〜6/28)

## 技術系
- コードベース知識グラフ - 検出: SA1 | 理由: 個人知識基盤とエージェントの長期記憶を、ソースコード探索にも応用できる。
- AIエージェント固有IDのライフサイクル管理 - 検出: SA4 | 理由: 人間の認証管理とは別に、短命なエージェントIDの発行、委任範囲、最小権限、即時失効を設計する新しい論点として掘り下げられる。
- AI出力の形式検証 - 検出: SA4 | 理由: 自動収集・実装エージェントの結果を数学的・機械的に検証する新しい品質保証手法として関連性が高い。
- 差動原子干渉計 - 検出: SA6 | 理由: 重力波・暗黒物質探索を支える次世代計測技術で、現在の技術関心から離れた科学領域を広げられる。
- 医療AIエージェントの評価設計 - 検出: SA6 | 理由: 自律エージェントの性能だけでなく、安全性、一般化、前向き試験という評価軸を学べる。
- エージェント前提のバージョン管理 - 検出: SA1 | 理由: 並行するAIエージェントの変更・競合・履歴をGitとは異なる設計で扱うOakは、現在のサブエージェント運用に直結する。
- GitHub Actions実行保護 - 検出: SA2 | 理由: workflow起動者とイベントをrulesetで制御する仕組みは、CIのローカル検証に加えて実行権限の境界設計を深掘りできる。
- 多言語ソース診断の文字位置変換 - 検出: SA2 | 理由: UTF-8バイト位置とUTF-16コード単位の差は、日本語を含むCLI・エディタ統合で再利用性の高い実装論点になる。
- エージェント運用ハーネス比較 - 検出: SA1 | 理由: Claude Code / Codex 向けの harness や ECC が複数出ており、サブエージェント運用を再現可能にする設計比較に向く。
- TypeScript Go移行準備 - 検出: SA2 | 理由: TypeScript 6.0 が 7.0 の Go 実装移行を意識した橋渡し版になっており、フロントエンド/CLI基盤の将来変更として追う価値がある。
- Swiftパッケージ配布基盤 - 検出: SA1 | 理由: Swift Package Index の Apple 参加は、macOS/Swift 開発で使う依存発見・配布インフラの変化として継続観測に向く。
- ローカル高速検索の低レイヤー実装 - 検出: SA1 | 理由: SSD 直接読み取り型の検索実験は、個人ナレッジベースやコード探索の速度限界を考える補助線になる。
- MacネイティブLinuxコンテナ - 検出: SA1 | 理由: Apple silicon と macOS 26 の仮想化機能を前提にした `apple/container` は、Tauri/Swift 開発環境やローカル検証の選択肢として追う価値がある。
- エージェント向けデザイン仕様 - 検出: SA1 | 理由: `design.md` のようなブランド・UI 指針ファイルは、生成 UI の品質をプロンプト依存から構造化された入力へ移す実装論点になる。
- AGENTS.mdを使うコードレビュー運用 - 検出: SA2 | 理由: Copilot code review が `AGENTS.md` を読むようになったことで、人間・Codex・他エージェントのレビュー規約を単一ファイルで揃える運用を検討できる。
- BYOK型エージェント運用 - 検出: SA2 | 理由: Copilot app の BYOK 対応は、モデル選択、課金、データ境界、ローカルモデル利用を組み合わせる実務設計に直結する。
- ECG深層学習バイオマーカー - 検出: SA6 | 理由: 既存の低コスト検査を AI で再評価する流れは、医療AIの実装と前向き検証の境界を学ぶ材料になる。
- AWSエージェント開発ツールキット - 検出: SA1 | 理由: MCP servers、skills、plugins をクラウド運用へ接続する実装論点として、Codex/Claude のツール運用設計に近い。
- in-page GUI agent - 検出: SA1 | 理由: ブラウザ操作をページ内エージェントとして扱う発想は、Playwright や Computer Use とは違う自動化境界を比較できる。
- 文書からLLM入力への変換基盤 - 検出: SA1 | 理由: PDF/Office を markdown/JSON に変換する MinerU は、個人ナレッジベースと調査自動化の入力品質に直結する。
- SwiftによるC実装置換 - 検出: SA2 | 理由: TrueType hinting interpreter の移植は、Swift を安全性と性能の両面で既存ネイティブ実装へ適用する具体例になる。
- GitHub Actionsステップ並列化 - 検出: SA2 | 理由: CI 内で background/wait/parallel を扱えると、ローカル検証ツールや複数サービス起動の設計にも応用できる。
- Vite大型アプリ開発モード最適化 - 検出: SA2 | 理由: Vite 8.1 の bundled dev mode は、React/Tauri フロントエンドの起動・HMR性能を追う観測点になる。
- 識別子なしメッセージング設計 - 検出: SA1 | 理由: SimpleX のような通信基盤は、アカウントID・ログ保持・メタデータ最小化を前提にしたアプリ設計の参考になる。
- Agentic Workflow Injection対策 - 検出: SA2 | 理由: GitHub Actions 上のエージェント入力境界を体系化する研究で、CIにAIを組み込むときの権限設計に直結する。
- AIエージェントの仮想環境ストレステスト - 検出: SA4 | 理由: Patronus AI の資金調達は、エージェントの実行失敗モードを本番前に検証する市場が立ち上がっていることを示す。
- AI数学支援と証明検証 - 検出: SA1 | 理由: 数学研究にAIが入る流れは、生成と形式検証の役割分担を考えるうえで既存の品質保証関心と接続しやすい。

## 非技術系
- 主権AIと国家インフラ - 検出: SA1・SA4 | 理由: オープンモデル、インド独自AI基盤、国家安全保障が交差する政策テーマとして継続観測に向く。
- 現代美術市場と国際展 - 検出: SA5 | 理由: Art Baselとヴェネチア・ビエンナーレを通じ、技術以外の文化・市場動向を定点観測できる。
- 永久凍土融解と岩石風化 - 検出: SA6 | 理由: 気候変動のフィードバックが単純な一方向ではないことを示す研究テーマで、科学ニュースの解像度を上げられる。
- AI音楽訓練データと創作者同意 - 検出: SA5 | 理由: AIツールへの技術的関心を、著作権・同意・対価という文化政策の側から検討できる。
- AIデータセンターの電源調達 - 検出: SA4 | 理由: 2.67GW規模のガス火力計画は、AI計算需要と脱炭素目標の衝突を追う具体的な観測点になる。
- 恒星間彗星の同位体化学 - 検出: SA6 | 理由: 3I/ATLASのD/H比から形成環境を推定する研究は、単一天体の観測と銀河進化モデルの接続を学べる。
- 欧州熱波と社会インフラ - 検出: SA3 | 理由: 記録的熱波が鉄道・学校・観光へ波及しており、気候変動を生活インフラの運用問題として追える。
- 防衛テック投資 - 検出: SA4 | 理由: 地政学リスクとAI/ドローン投資が結びついており、通常のスタートアップ投資とは異なる政策・安全保障軸を学べる。
- 文化フェスのキュレーション設計 - 検出: SA5 | 理由: Olivia Rodrigo の女性主導フェスは、音楽作品だけでなく「場を設計する」文化的な動きとして観測できる。
- 軌道上サービスと宇宙望遠鏡延命 - 検出: SA6 | 理由: Swift宇宙望遠鏡の救出計画は、商業宇宙企業が科学観測インフラの寿命を延ばす新しい役割を示している。
- 台湾周辺の灰色地帯海上圧力 - 検出: SA3 | 理由: 軍事演習だけでなく商船管制や航行ルールを使う圧力は、台湾有事を物流・国際法の観点から見る入口になる。
- ライブ料金と文化アクセス - 検出: SA5 | 理由: チケット価格高騰は音楽体験の格差を広げるテーマで、作品評価とは別に文化消費の構造を追える。
- 映像制作AIと労働組合 - 検出: SA5 | 理由: 生成AIの創作利用を、技術デモではなく職能・クレジット・労働条件の問題として観測できる。
- AI・宇宙投資ファンド - 検出: SA4 | 理由: Valor の大型ファンドは、モデル企業だけでなく宇宙・半導体・インフラへ資本が流れる構造を追う具体例になる。
- 火星生命痕候補の解釈 - 検出: SA6 | 理由: Perseverance の有機物検出は、発見報道を「証拠」と「可能性」に分けて読む科学リテラシーの題材になる。
- ウクライナ復興金融 - 検出: SA3 | 理由: EU の復興融資は、戦時支援を軍事援助から国家再建パッケージへ広げる動きとして継続観測に向く。
- ホルムズ海峡の海上リスク - 検出: SA3 | 理由: 商船攻撃と避難航路停止は、エネルギー流通と地政学が直結する具体的なリスク管理テーマになる。
- AI半導体の非スマホ転換 - 検出: SA4 | 理由: Qualcomm のデータセンター拡大計画は、AIインフラ需要が既存半導体企業の事業構造を変える例として追える。
- 計算資源の長期契約 - 検出: SA4 | 理由: Reflection と SpaceXAI の契約は、モデル開発競争で compute 調達そのものが戦略資産になる流れを示している。
- super-puff 惑星 - 検出: SA6 | 理由: 低密度巨大惑星は、惑星形成や大気保持を学ぶ入口として、宇宙科学の関心領域を広げられる。
- Microbiome基盤モデルの頑健性 - 検出: SA6 | 理由: 分布シフト下での性能劣化は、医療AIの「精度だけでは足りない」評価設計を考える材料になる。
- 気候変動の迅速帰属研究 - 検出: SA3 | 理由: 欧州熱波を単なる災害報道ではなく、科学的帰属と都市インフラ適応の問題として読める。
- 分子拡大顕微鏡 - 検出: SA6 | 理由: 試料を膨張させて低コスト装置の解像度を上げる発想は、研究インフラの民主化という観点で面白い。
- 土壌細菌由来の抗菌薬設計 - 検出: SA6 | 理由: 耐性菌対策を単一薬剤ではなく複数標的の組み合わせとして捉える研究テーマを追える。
- 乳牛H5N1の農場運用対策 - 検出: SA6 | 理由: 搾乳コホート分割や検査設計が公衆衛生に直結する、科学と現場運用の接点として観測価値がある。
- AI安全性レポートの読み比べ - 検出: SA2 | 理由: モデル単体の性能ではなく、評価・政策・社会リスクを横断する資料を継続的に追うとエージェント設計判断に使える。
- AI企業IPOと公開市場評価 - 検出: SA4 | 理由: OpenAI の IPO 観測は、AI 開発企業の資金調達とガバナンスが公開市場へ移る変化として継続観測に向く。
