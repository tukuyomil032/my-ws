# 興味提案 W3 (7/15〜7/21)

## 技術系
- Work agentとしてのCodex - 検出: SA1 | 理由: Codex / ChatGPT Work の広がりは、coding agent を汎用 work agent として運用する流れを見る材料になる。
- Codex利用行動の変化 - 検出: SA2 | 理由: 複数agent管理やskills利用の増加は、agentic AIが仕事単位を変える兆候として追える。
- Agent safety hooks - 検出: SA1 | 理由: destructive_command_guard は、Codex / Claude Code のような agent 実行環境で危険操作をどう止めるかを実装面から追える。
- Open-weight multimodal model - 検出: SA1 | 理由: Inkling は closed work agent だけでなく、open-weight 側の長文・ multimodal model 競争を見る入口になる。
- Frontend tooling patch stability - 検出: SA2 | 理由: Biome / Vitest の patch release は、大型機能よりも日常開発の lint / test 安定性を支える更新として追う価値がある。
- Agent-ready creator tools - 検出: SA1 | 理由: OpenCut の MCP server / headless mode 構想は、動画編集のようなクリエイティブツールにも agent 操作前提が入り始めていることを示す。
- Self-hosted runner governance - 検出: SA2 | 理由: GitHub Actions runner の enforcement は、CI を長く安定運用するうえで image 更新・auto-update・監査ログ確認を routine 化する必要を示している。
- Gemini Notebook migration - 検出: SA2 | 理由: NotebookLM 改称は my-ws の月次 podcast / knowledge base 導線に直接関わるため、名称変更や redirect の影響を追う価値がある。
- Semantic metadata for AI systems - 検出: SA1 | 理由: Apache OSSIE は、AI・分析・BIを意味メタデータで接続する標準化の入口として追える。
- Tauri ecosystem release coordination - 検出: SA2 | 理由: Tauri v2のRust crate・JS API・CLI・WebView層をまとめて更新する運用は、desktop appの依存管理に直結する。

## 非技術系
- AI創薬資本市場 - 検出: SA4 | 理由: Chai Discovery の大型調達は、医療AIが研究だけでなく投資テーマとして伸びていることを示す。
- Panda Bear / Sonic Boomの制作変化 - 検出: SA5 | 理由: サンプル依存から自己録音素材へ寄せる変化は、音楽制作の美学と技術の関係を見る素材になる。
- 星間有機分子と生命起源 - 検出: SA6 | 理由: 星間糖分子の検出は、生命材料が太陽系形成前から存在した可能性を考える入口になる。
- 欧州防衛産業の内製化 - 検出: SA3 | 理由: EU・ウクライナ共同生産は、武器供与から生産能力再編へ移る欧州安全保障の変化を追う材料になる。
- 予防医療スキャン市場 - 検出: SA4 | 理由: Neko Health の大型調達は、AI創薬とは別軸で医療テックが資本を集める領域として観測できる。
- 既存楽曲の再解釈アルバム - 検出: SA5 | 理由: Meshell Ndegeocello の `Synonym` は、カバー制作を文化的・政治的意味づけとして見る入口になる。
- 初期宇宙クエーサー観測 - 検出: SA6 | 理由: Euclid によるクエーサー候補群は、初期宇宙と巨大ブラックホール形成を追う継続テーマになりうる。
- 戦時下の防衛改革政治 - 検出: SA3 | 理由: ウクライナ国防相更迭への抗議は、ドローン戦・軍改革・政治的統治の緊張を同時に見る材料になる。
- 垂直AIエージェント市場 - 検出: SA4 | 理由: Fora の旅行代理店向け AI assistant は、汎用 chatbot ではなく業務特化 agent が評価額を得る流れを追える。
- 宇宙滞在とミトコンドリア - 検出: SA6 | 理由: 微小重力が mitochondrial protein production に影響する経路は、長期宇宙滞在や生命科学の継続テーマになりうる。
- Embedded coding agents - 検出: SA1 | 理由: Copilot SDK は coding agent が IDE の中だけでなく、外部アプリやサービスに組み込まれる方向を追う入口になる。
- TypeScript native compiler migration - 検出: SA2 | 理由: TypeScript 7 の Go 移植は、大規模 TS repo の CI / editor latency と agent feedback loop に直接効く可能性がある。
- Xcode runner image governance - 検出: SA2 | 理由: Xcode 27 runner preview は、Swift / macOS アプリの CI を Apple SDK 更新にどう追従させるかを見る材料になる。
- South China Sea information friction - 検出: SA3 | 理由: 中国メディア動画へのフィリピン抗議は、海上対立が法的・軍事的領域だけでなく情報発信にも広がる例として追える。
- National AI infrastructure capex - 検出: SA4 | 理由: NVIDIA / Noetra / METI の AI factory は、AI 投資を個別スタートアップではなく国家インフラとして見る視点を補強する。
- AI-generated music metadata - 検出: SA5 | 理由: Lorde の Spotify AI 楽曲解説批判は、生成AIが作品解釈や音楽体験のUIをどう変えるかを考える材料になる。
- Habitable-zone atmosphere detection - 検出: SA6 | 理由: LHS 1140b の大気観測は、生命存在の断定ではなく、居住可能圏惑星を観測対象として絞り込む継続テーマになる。
- AI-mediated dating design - 検出: SA4 | 理由: Overtoneは、スワイプ中心の既存UIを避けて音声・AIで紹介するプロダクト設計を追う材料になる。
- Environmental disaster as trade friction - 検出: SA3 | 理由: カナダ山火事の越境煙が関税議論へ波及する事例は、気候災害と国際経済の接続を見る入口になる。
- 国家安全保障とAIインフラ - 検出: SA3・SA4 | 理由: ホルムズ海峡や核抑止と、国家単位のAI・半導体投資を同じリスク地図で追える。
- 生成AI時代の文化助成とデザイン - 検出: SA5 | 理由: AIによる平均化への反作用と、公的助成・表現規制の論点がUI/文化設計に接続する。
- 予防医療のマルチオミクス - 検出: SA6 | 理由: 血液検査で長期リスクを推定する研究は、AI医療の精度だけでなく臨床導入・過剰診断まで考える入口になる。
