# 興味提案 W3 (7/15〜7/21)

## 技術系
- Work agentとしてのCodex - 検出: SA1 | 理由: Codex / ChatGPT Work の広がりは、coding agent を汎用 work agent として運用する流れを見る材料になる。
- Codex利用行動の変化 - 検出: SA2 | 理由: 複数agent管理やskills利用の増加は、agentic AIが仕事単位を変える兆候として追える。
- Agent safety hooks - 検出: SA1 | 理由: destructive_command_guard は、Codex / Claude Code のような agent 実行環境で危険操作をどう止めるかを実装面から追える。
- Open-weight multimodal model - 検出: SA1 | 理由: Inkling は closed work agent だけでなく、open-weight 側の長文・ multimodal model 競争を見る入口になる。
- Frontend tooling patch stability - 検出: SA2 | 理由: Biome / Vitest の patch release は、大型機能よりも日常開発の lint / test 安定性を支える更新として追う価値がある。

## 非技術系
- AI創薬資本市場 - 検出: SA4 | 理由: Chai Discovery の大型調達は、医療AIが研究だけでなく投資テーマとして伸びていることを示す。
- Panda Bear / Sonic Boomの制作変化 - 検出: SA5 | 理由: サンプル依存から自己録音素材へ寄せる変化は、音楽制作の美学と技術の関係を見る素材になる。
- 星間有機分子と生命起源 - 検出: SA6 | 理由: 星間糖分子の検出は、生命材料が太陽系形成前から存在した可能性を考える入口になる。
- 欧州防衛産業の内製化 - 検出: SA3 | 理由: EU・ウクライナ共同生産は、武器供与から生産能力再編へ移る欧州安全保障の変化を追う材料になる。
- 予防医療スキャン市場 - 検出: SA4 | 理由: Neko Health の大型調達は、AI創薬とは別軸で医療テックが資本を集める領域として観測できる。
- 既存楽曲の再解釈アルバム - 検出: SA5 | 理由: Meshell Ndegeocello の `Synonym` は、カバー制作を文化的・政治的意味づけとして見る入口になる。
- 初期宇宙クエーサー観測 - 検出: SA6 | 理由: Euclid によるクエーサー候補群は、初期宇宙と巨大ブラックホール形成を追う継続テーマになりうる。
