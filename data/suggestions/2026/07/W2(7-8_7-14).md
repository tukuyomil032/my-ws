# 興味提案 W2 (7/8〜7/14)

## 技術系
- Coding agent性能最適化評価 - 検出: SA1 | 理由: エージェントが正しいコードだけでなく速いコードを書けるかを測る評価軸として重要。
- 科学解析multi-agent workflow - 検出: SA2 | 理由: 専門処理を複数エージェントに分ける設計は、知識収集や研究補助の自動化に応用できる。
- Self-evolving agent tooling - 検出: SA1 | 理由: ルーティンで得た手順や失敗パターンを再利用可能なツールへ昇格する発想に近い。
- Agent RLの探索配分 - 検出: SA2 | 理由: 長手数エージェントの品質を上げるには、探索と収束のバランスを理解する必要がある。
- Web agent prompt injection対策 - 検出: SA1 | 理由: ブラウザ操作エージェントでは、ページ内の不信コンテンツをどう隔離するかが実装上の核心になる。
- AI coding tool競争地図 - 検出: SA1 | 理由: Perplexity のような検索系企業も coding tool に入ることで、Codex/Cursor/Claude Code 周辺の競争軸を見直せる。
- 医療AI助言の行動影響 - 検出: SA2 | 理由: 医療AIは正答率だけでなく、医師や患者の行動をどう変えるかが評価対象になる。

## 非技術系
- 地政学ニュースの市場波及 - 検出: SA3 | 理由: 停戦発言や海峡リスクが油価・株価へどう伝播するかを見ると、世界情勢と経済を接続して読める。
- Surprise release戦略 - 検出: SA5 | 理由: 音楽リリースの告知・即時配信・SNS拡散の設計を観察できる。
- Roman Space Telescope - 検出: SA6 | 理由: 広視野宇宙望遠鏡は、暗黒エネルギーや系外惑星探索の基盤として継続観測に向く。
- 防空生産ライセンス - 検出: SA3 | 理由: 軍事支援を装備供与ではなく生産能力移転として読む観点を得られる。
- Consumer social trust - 検出: SA4 | 理由: Partiful の成長とデータ懸念は、若年層向けサービスの信頼設計を考える材料になる。
- Phone-free listening event - 検出: SA5 | 理由: スマホ制限イベントは、鑑賞体験とSNS拡散のバランスを設計する文化的実験として見られる。
- 希少ガス供給網 - 検出: SA3 | 理由: ヘリウムのような資源は半導体・医療の両方に効くため、地政学を産業供給網として読める。
- 週次新譜キュレーション - 検出: SA5 | 理由: 単発レビューより、複数ジャンルを横断した週次整理で文化トレンドを見やすくなる。
- JWST科学コミュニケーション - 検出: SA6 | 理由: 記念画像は研究成果だけでなく、観測装置の価値を一般に伝える設計として見られる。
- ホルムズ海峡と物流リスク - 検出: SA3 | 理由: エネルギー chokepoint は軍事だけでなく保険・物流・価格へ波及するため継続観測に向く。
- 音楽とファッションの交差イベント - 検出: SA5 | 理由: ANOHNI と Balenciaga のような事例は、音楽がファッション文脈で再提示される動きを追える。
- 月間skywatching guide - 検出: SA6 | 理由: 論文以外の一般向け天文観測情報も、科学関心を日常に接続する入口になる。
