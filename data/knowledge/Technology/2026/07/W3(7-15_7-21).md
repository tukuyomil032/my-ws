## 2026-07-17 - 技術深層

### GitHub Actions
- [GitHub Actions: Minimum version enforcement timeline for self-hosted runners](https://github.blog/changelog/2026-06-12-github-actions-minimum-version-enforcement-timeline-for-self-hosted-runners/)
  > self-hosted runner の minimum version enforcement が再開され、登録には `2.329.0` 以上、job execution には各 runner release から 30 日以内の更新が必要になる。Data Residency では 2026-07-31、GitHub Enterprise Cloud では 2026-09-25 に full enforcement が始まるため、runner image や auto-update disabled 環境の棚卸しが必要になる。
