- [Run Ray on TPU, Part 1: The foundations](https://developers.googleblog.com/en/run-ray-on-tpu-part-1-the-foundations/) - Google Developers Blogは、Ray 2.55でGoogle Cloud TPUが公式に第一級アクセラレーターとなり、GKEのKubeRayとTPUスライスのトポロジーを使って分散Pythonワークロードを実行できると説明している。TPUはチップ単位ではなく、ICIで結ばれたスライス全体を割り当てる必要がある点が実装上の要所で、APIはalphaと明記されている。（2026-07-20公開）

## 2026-07-25 - 技術トレンド・深層（SA1/SA2採用分）

### AI開発基盤 / 分散実行
- [Run Ray on TPU, Part 2: Ray AI libraries](https://developers.googleblog.com/run-ray-on-tpu-part-2-ray-ai-libraries/) - Googleは、Ray Serve・Ray Data・Ray TrainをTPUスライス上で使う具体例を公開した。`topology` の指定でマルチホストモデルを一つのICIメッシュへ配置し、`iter_jax_batches()` はJAX配列をデバイスシャーディング済みで供給、`JaxTrainer` はチェックポイントと障害復旧を担うため、アクセラレーターの性能だけでなく配置と入力パイプラインが運用の要点になる。（2026-07-24公開）

### coding agent / モデル選択
- [Claude Opus 5 is now available in GitHub Copilot](https://github.blog/changelog/2026-07-24-claude-opus-5-is-now-available-in-github-copilot/) - GitHub CopilotでClaude Opus 5が段階展開され、VS Code・Copilot CLI・cloud agent・Xcodeなどから選択できるようになった。GitHubの説明では、長時間のコーディング、複数ツールの調整、変更後の回帰検証を想定しており、利用可能プランと管理者ポリシーの条件も明記されている。（2026-07-24公開）

### 非同期 coding agent / 開発ワークフロー
- [Copilot cloud agent for Linear is now generally available](https://github.blog/changelog/2026-07-23-copilot-cloud-agent-for-linear-is-now-generally-available/) - LinearのIssueをCopilot cloud agentへ割り当てると、エージェントが非同期にIssueを解析し、専用の一時開発環境で作業してドラフトPRを作成できる。モデル、カスタムエージェント、ベース/作業ブランチ、実行中の指示変更までIssue単位で設定できるため、モデル選択だけでなくレビュー境界と実行環境を含む運用設計が要点になる。（2026-07-23公開）
