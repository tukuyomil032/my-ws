- [Directional AI Advice](https://arxiv.org/abs/2607.08706)

## 2026-07-12 - 技術トレンド

### CLI coding agent adoption
- [Adoption and Impact of Command-Line AI Coding Agents](https://arxiv.org/abs/2607.01418)
  > Microsoft の 2026 年前半 rollout を対象に、Claude Code と GitHub Copilot CLI の採用・継続・PR 影響を測った研究。組織導入ではモデル性能だけでなく、同僚経由の拡散、利用継続、token spend と成果指標の結びつきが重要になる。

## 2026-07-12 - 技術深層

### AI-native software engineering
- [From Determinism to Delegation](https://arxiv.org/abs/2606.28791)
  > AI-native software engineering を、コードを書く作業から agent workflow を監督する作業への移行として整理する論文。正しさを二値のテスト結果だけでなく、確率的評価・監督・責任分界として捉える点が、Codex 運用設計に近い。
