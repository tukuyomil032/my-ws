### 医療AI
- [Directional AI Advice](https://arxiv.org/abs/2607.08706)
  > 医療現場で AI 助言が処方、検査、患者満足度へどう影響するかを扱うプレプリント。AI の助言は正答率だけでなく、臨床判断と行動変化にどう介入するかを評価する必要がある。

## 2026-07-12 - 技術トレンド

### Coding agent interpretability
- [Latent Programming Horizons in Coding Agents](https://arxiv.org/abs/2607.05188)
  > coding agent の hidden states が、現在の code が parse できるか、test に通るか、将来の edit が成功しそうかを先取りして表現している可能性を調べる研究。agent の自己評価や検証設計を、外からの test だけでなく内部表現の観測へ広げる視点がある。

## 2026-07-12 - 技術深層

### Agent tool surface
- [When Does Restricting a Coding Agent to execute_code Help?](https://arxiv.org/abs/2607.10569)
  > Claude Code と OpenAI Codex CLI を含む比較で、bash / IDE primitives / MCP execute_code の tool surface が cost と成功率にどう影響するかを調べる研究。agent 設計では「道具を増やすほど良い」とは限らず、task regime と agent design の組み合わせで安い surface が変わる。

## 2026-07-13 - 技術トレンド

### Agent access analytics
- [Developer Experience with AI Coding Agents](https://arxiv.org/abs/2604.02544)
  > AI coding agent が documentation portal をどう読むかを HTTP fingerprint から分析する研究。agent は人間のように複数ページを辿らず、少数 request に情報取得を圧縮するため、従来の time-on-page や click path が利用実態を表しにくくなる。

## 2026-07-13 - 技術深層

### Agentic software engineering curriculum
- [ASE-26](https://arxiv.org/abs/2606.01152)
  > agentic software engineering を学部教育として構造化する curriculum 提案。agent を使えるかではなく、意図、検証、進化的な作業ループをどう訓練するかに焦点を置いており、個人の開発習慣を設計する材料になる。

## 2026-07-14 - 技術トレンド

### AI delivery reliability
- [AI has slashed coding time in 2026, but it has sacrificed software stability](https://www.techradar.com/pro/ai-has-slashed-coding-time-in-2026-but-its-sacrificed-software-stability) - AI-assisted coding で実装速度は上がる一方、古い delivery pipeline のままだと障害対応や QA 側へ負荷が移るという整理。agent 導入は coding speed だけでなく、rollback、feature flag、検証自動化まで含めた運用設計が必要になる。
