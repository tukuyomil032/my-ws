# 技術トレンド・深層記事 W3 (9/15〜9/21)

## 2026-09-19

### GitHub ActionsのWorkflow Execution Protectionsが一般提供

GitHubは、誰がどのイベントでActions workflowを起動できるかを制御するWorkflow Execution Protectionsを一般提供した。workflowファイル単位の対象指定、評価モード、REST APIによるポリシー管理に対応し、公開リポジトリでは`pull_request_target`の危険な既定挙動を抑える保護も段階導入されるため、CIの権限境界と監査可能性を一体で設計できる。取得日: 2026-09-19。出典: [GitHub Changelog](https://github.blog/changelog/2026-09-17-workflow-execution-protections-in-github-actions-generally-available/)

### Rust 1.98.1がvtable生成の誤コンパイルを修正

Rust 1.98.1は、1.98.0で一部のtrait object vtableに本来の関数ポインタではなくnullポインタが生成され得る問題を修正した。未定義動作やクラッシュにつながる不具合であり、Rustをネイティブアプリや長時間動くレンダラーへ使う場合は、ツールチェーンの更新をCIと配布環境で明示的に固定する必要がある。取得日: 2026-09-19。出典: [Rust Blog](https://blog.rust-lang.org/releases/latest/)

### GitHub Copilot CLIでモデルの適応的オーケストレーションを実験導入

GitHubの9月7日週のCopilot更新では、Copilot CLIの実験機能としてHydraFusionによるローカル・クラウド・複合モデル間の自動ルーティングが紹介された。エージェントの作業を単一モデル前提から、タスクや実行環境に応じたモデル選択へ広げる動きとして、個人のマルチハーネス運用にも関係する。取得日: 2026-09-19。出典: [GitHub Copilot weekly releases](https://github.blog/changelog/2026-09-10-github-copilot-weekly-releases-september-7/)

## 2026-09-21

### DARPAが深部神経信号の非侵襲光学計測をBCI研究へ展開

DARPAは、人間の皮質深部に相当する深さから神経信号を記録できる非侵襲のコヒーレント光学システムを基盤に、脳・コンピューター・インターフェースの技術課題を解くFirefoxプログラムの提案者向け説明会を開催した。研究公募の段階で、計測可能性だけでなく、信号取得を実用的なBCIへつなぐ技術課題を明示している点が重要である。取得日: 2026-09-21。出典: [DARPA Proposer Day: Firefox](https://www.darpa.mil/events/2026/proposer-day-firefox)

## 2026-09-20

### Microsoft Foundry Toolkit 1.6.13がエージェント開発機能を拡張

Microsoft Foundry Toolkit for VS Codeの1.6.13では、private container registry接続、AMD NPU向けFaraモデル、Aion fine-tuning adapter、Hosted Agent検証、Agent Inspectorの改善が追加された。モデル検索やエージェント診断だけでなく、配布資源の欠落・空フォルダをエラーとして扱う変更も含まれ、エージェント開発の運用面を強化している。取得日: 2026-09-20。出典: [Microsoft Foundry Toolkit release notes](https://github.com/microsoft/foundry-dev-tools/blob/main/WHATS_NEW.md)

### OpenAIのJalapeñoチップ設計でLLMを高位設計・検証に組み込む

IEEE Spectrumの報告では、OpenAIの初のAIアクセラレータJalapeñoは、アーキテクチャ構想からfirst siliconまで20か月未満、RTLからtape-outまで9か月で進み、LLMをXLSなどソフトウェアに近い高位設計・検証作業へ組み込んだ。Broadcomがゲート以降のphysical designを担っており、速度の数字はLLM単独ではなく、人間の設計判断・自動化ツール・外部パートナーの分業として読む必要がある。取得日: 2026-09-20。出典: [IEEE Spectrum](https://spectrum.ieee.org/llms-for-chip-design)
