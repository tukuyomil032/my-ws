# 技術トレンド・深層記事 W3 (9/15〜9/21)

## 2026-09-19

### GitHub ActionsのWorkflow Execution Protectionsが一般提供

GitHubは、誰がどのイベントでActions workflowを起動できるかを制御するWorkflow Execution Protectionsを一般提供した。workflowファイル単位の対象指定、評価モード、REST APIによるポリシー管理に対応し、公開リポジトリでは`pull_request_target`の危険な既定挙動を抑える保護も段階導入されるため、CIの権限境界と監査可能性を一体で設計できる。取得日: 2026-09-19。出典: [GitHub Changelog](https://github.blog/changelog/2026-09-17-workflow-execution-protections-in-github-actions-generally-available/)

### Rust 1.98.1がvtable生成の誤コンパイルを修正

Rust 1.98.1は、1.98.0で一部のtrait object vtableに本来の関数ポインタではなくnullポインタが生成され得る問題を修正した。未定義動作やクラッシュにつながる不具合であり、Rustをネイティブアプリや長時間動くレンダラーへ使う場合は、ツールチェーンの更新をCIと配布環境で明示的に固定する必要がある。取得日: 2026-09-19。出典: [Rust Blog](https://blog.rust-lang.org/releases/latest/)

### GitHub Copilot CLIでモデルの適応的オーケストレーションを実験導入

GitHubの9月7日週のCopilot更新では、Copilot CLIの実験機能としてHydraFusionによるローカル・クラウド・複合モデル間の自動ルーティングが紹介された。エージェントの作業を単一モデル前提から、タスクや実行環境に応じたモデル選択へ広げる動きとして、個人のマルチハーネス運用にも関係する。取得日: 2026-09-19。出典: [GitHub Copilot weekly releases](https://github.blog/changelog/2026-09-10-github-copilot-weekly-releases-september-7/)
