## 2026-08-15 - 技術トレンド・深層

### ローカルAI・エージェント
- [lightningpixel/modly](https://github.com/lightningpixel/modly) - 画像やプロンプトからGPU上のローカルAIだけで3Dメッシュを生成するデスクトップアプリ。クラウドAPIを前提にせず、生成モデルを制作ツールへ組み込む実装例として確認できる。
- [Unsloth](https://github.com/unslothai/unsloth) - LLMや拡散モデルのローカル実行・学習を支援し、Claude CodeやCodexとの接続も想定するツール。モデルを使うだけでなく、手元の計算資源で調整・運用する導線を一つのプロジェクトにまとめている。

### Codex / OpenAI
- [Custom Code Review rules for Codex](https://developers.openai.com/blog/custom-code-review-rules-for-codex) - Codex Code Reviewが`AGENTS.md`のリポジトリ固有ルールを読み、互換性やデータ境界などの不変条件をレビューへ持ち込めるようになった。ルールを広げすぎず、`rawResponseItem/*`のような具体的な破壊点を短く書くことがノイズ低減につながる。
- [Making private MCP servers reachable without making them public](https://developers.openai.com/blog/connect-private-mcp-servers-to-openai-products) - Secure MCP Tunnelは、MCPサーバーを公開せずにChatGPTやCodexへ接続する構成を解説する。顧客側クライアントがoutbound HTTPSで接続を張り、streamingと認証を維持しながら私設ネットワークの境界を保つ設計や。

### Apple開発環境
- [Xcode 26 Release Notes](https://developer.apple.com/documentation/Xcode-Release-Notes/xcode-26-release-notes) - Xcode 26はSwift 6.2と各OSの26系SDKを含み、ChatGPT / Claudeアカウント連携やローカルモデル利用まで開発体験に取り込んでいる。Compilation Caching、Swift concurrency debugging、SwiftUI / Instrumentsの強化も含まれる公式リリースノートや。
